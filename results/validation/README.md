# results/validation/

Validation and determinism records backing the ADRs (determinism gates, cross-engine checks). Not benchmark seeds: never indexed by a manifest or counted in the papers. One JSON per check with `validation`, `adr`, `date`, `engine`, `image`, `params`, `result` (PASS/FAIL/INFO), `data`, `conclusion`, `reproduce`. Append new records; do not rewrite old ones.
