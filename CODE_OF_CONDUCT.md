# Code of Conduct

Participation in this project (issues, pull requests, discussions) is expected
to stay professional:

- Be respectful. No harassment, personal attacks, or abusive language.
- Keep discussion technical and on topic.
- Do not publish others' private information.

Unacceptable behavior can be reported to brendanchambersbou@gmail.com. The
maintainer may edit or remove comments, commits, issues, and other
contributions that violate these expectations, and may block repeat offenders.
